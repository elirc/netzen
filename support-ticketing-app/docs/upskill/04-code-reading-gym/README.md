# 04 Code Reading Gym

This gym turns reading into practice. Every exercise points at real code and asks for annotations, traces, review findings, or contrasts.

Use this loop:

1. Read the anchor.
2. Annotate inputs, outputs, dependencies, invariants, side effects, failure modes.
3. Predict one bug or risk.
4. Write one check that would catch it.
5. Self-grade: Basic, Solid, Strong.
