# 06 Contribution Practice

Contribution practice turns reading into useful changes. Start with good-first tickets that touch one boundary, move to mid-level cross-layer tickets, then use senior projects to practice design, migration, testing, rollout, and risk tradeoffs.

Before any ticket:

1. Read relevant anchors.
2. State blast radius.
3. Write acceptance criteria.
4. Choose tests before implementation.
5. Keep refactors separate unless the ticket asks for them.

Use `05-feature-user-stories-implementation-plans.md` when you want larger feature practice: it contains 20 user stories with junior-friendly implementation plans, examples, references, risks, and suggested checks.
